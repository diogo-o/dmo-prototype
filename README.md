# DMO Prototype

Protótipo navegável do Portal DMO para GitHub Pages.

A aplicação estática encontra-se na raiz deste repositório. Abra `index.html` através do GitHub Pages. As contas e os fluxos usam dados de demonstração guardados no navegador; não existe autenticação de produção nem sincronização entre dispositivos.

As especificações e o funcionamento dos módulos são mantidos separadamente em [`beta-design`](https://github.com/diogo-o/beta-design).

Para publicar: GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
